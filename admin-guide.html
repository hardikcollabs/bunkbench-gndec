Owner guide — content is managed through the GitHub repository.

Keep the bench fresh.

This is a static reference page, not a secure admin panel. There is no login and no upload button. Make changes through GitHub.

01 · PDFs

Add a resource

Put the original file in resources/, then add an object to data/resources.js. Keep the filename simple and never replace a source document with a screenshot or invented summary.

{ id: "new-note", title: "New notes", semester: "Semester 3",
subject: "Metallurgy", type: "Notes", description: "Short description",
fileLink: "resources/new-note.pdf", officialSourceLink: "",
dateAdded: "2026-11-04", featured: true }
02 · Updates

Add a student update

Open data/updates.js and add an object. Use isOfficialSource: true only for the actual GNDEC or department URL.

03 · Memes

Add a meme

Put an approved image in assets/memes/, then add its path, caption, credit, and approval status in data/memes.js.

04 · Subjects

Update a subject

Edit the matching object in data/subjects.js. To add one, include a unique slug, name, intro, icon, semester, and units.

05 · Publish

Preview, commit, push

Preview locally if useful, then commit and push to main. GitHub Pages publishes the update after its workflow succeeds. If the workflow fails, check Actions before telling students the change is live.

06 · Please protect people

Content reminder

Do not upload personal data, private notices, or copyrighted books without permission. Keep the public site student-made and clearly unofficial.
